# 🕹️ Tic Tac Toe Game

A simple, lightweight Tic Tac Toe game built using HTML, CSS, and JavaScript.
This project demonstrates basic DOM manipulation, game logic implementation, and responsive UI styling.

## 🚀 Features
- Two-player mode  
- Win/draw detection  
- Reset button  
- Clean and minimal UI
